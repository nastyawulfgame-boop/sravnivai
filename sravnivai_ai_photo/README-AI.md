# Сравнивай — распознавание фото без платного API и Node.js

## Что работает
- Фото товара можно выбрать с телефона или компьютера.
- Бесплатная модель CLIP загружается из публичного CDN и запускается в браузере пользователя.
- Не нужны OpenAI API key, платный ключ, Node.js, npm или собственный сервер.
- После распознавания можно искать похожие товары во всех списках, сохранённых в этом браузере.
- Каталог продолжает сохраняться в `localStorage` браузера.

## Важные ограничения
- При первом распознавании браузер должен скачать библиотеку и модель из интернета; это может занять время и потребовать заметного интернет-трафика.
- Модель определяет примерную категорию предмета, но не гарантирует точное название, бренд или модель.
- Поиск работает только по товарам, которые пользователь уже добавил в свои списки. Интернет-магазины и цены в интернете не ищутся.
- Каталог хранится локально в конкретном браузере и не синхронизируется автоматически между устройствами.
- Для запуска из `file://` некоторые браузеры могут блокировать ES-модули. Надёжнее опубликовать статические файлы через GitHub Pages.

## Самый простой запуск через GitHub Pages (бесплатно)

1. Распакуйте архив.
2. Откройте свой репозиторий GitHub `sravnivai`.
3. Загрузите в репозиторий файлы проекта с заменой старых файлов, если GitHub спросит. Для этого варианта серверные файлы `server.js`, `package.json` и `.env.example` больше не нужны.
4. В репозитории откройте **Settings → Pages**.
5. В блоке **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` (или ту, где находятся файлы) и папку `/ (root)`, затем нажмите **Save**.
7. Дождитесь публикации. Адрес сайта появится в разделе Pages; откройте его и перейдите в `tovari.html`.
8. Нажмите **Выбрать фотографию → Распознать товар**. При первом запуске разрешите загрузку ресурсов и дождитесь, пока модель подготовится.

Если проект опубликован не в корне сайта, откройте адрес Pages с `/tovari.html` в конце.

## Использование
1. Добавьте товары в один или несколько списков каталога.
2. Выберите фото предмета (JPG, PNG или WebP, до 8 МБ).
3. Нажмите **Распознать товар** и дождитесь результата.
4. Нажмите **Найти похожие товары в каталоге**. Результаты покажут товары из всех сохранённых списков.

## Конфиденциальность
Изображение не отправляется на OpenAI или на собственный сервер проекта: модель обрабатывает его в браузере. Для загрузки библиотеки и модели требуется подключение к публичным CDN/репозиторию модели. Сам файл фото не отправляется этим кодом на сервер распознавания.
