# Сравнивай — распознавание товаров по фото

## Что добавлено
- Блок «Найти товар по фото» на странице `tovari.html`.
- Предпросмотр изображения и проверка типа/размера файла.
- Серверный endpoint `/api/analyze-image`, который передаёт изображение модели OpenAI с поддержкой зрения.
- Результат на русском: название, категория, бренд (если распознаётся), описание, видимые детали и поисковые запросы.
- Кнопка поиска совпадений в товарах текущего списка.
- API-ключ хранится на сервере в `.env`, а не в браузере.

## Запуск локально
Нужен Node.js 18 или новее и API-ключ OpenAI с доступом к API.

1. Распакуй архив.
2. В терминале в папке проекта выполни:
   ```bash
   npm install
   ```
3. Скопируй `.env.example` в `.env`.
4. В `.env` замени `вставь_свой_ключ_сюда` на свой API-ключ. Не публикуй этот файл и не загружай его в GitHub.
5. Запусти:
   ```bash
   npm start
   ```
6. Открой `http://localhost:3000/tovari.html`.

Не открывай `tovari.html` двойным нажатием как `file://`: для API нужен работающий сервер.

## Важно
- Распознавание требует подключения к интернету, действительного OpenAI API key и доступного лимита API. Оплата API может быть отдельной от подписки ChatGPT.
- ИИ не всегда может определить точную модель/бренд только по фотографии.
- В статическом хостинге без серверной части endpoint не заработает. При публикации разверни Node.js сервер и задай `OPENAI_API_KEY` как переменную окружения на хостинге.
