# Авторизация — папка для разработчика

Файл `auth.js` содержит демонстрационную регистрацию и вход для статической версии проекта.

- Пользователи хранятся в `localStorage` текущего браузера под ключом `sravnivaiUsers_v1`.
- Пароль не хранится открытым текстом: сохраняется SHA-256-хеш.
- Текущая сессия хранится отдельно под ключом `sravnivaiSession_v1`.
- Работает локально в браузере и на HTTPS-хостинге (например, GitHub Pages).

**Важно:** это учебный клиентский пример, не настоящая защищённая авторизация. Данные браузера можно изменить через инструменты разработчика, а аккаунты не синхронизируются между устройствами. Для реального публичного сервиса нужна серверная авторизация или managed auth (например, Supabase/Firebase), серверное хеширование паролей с солью и ограничение попыток входа. Никогда не храните пароли в открытом виде.
