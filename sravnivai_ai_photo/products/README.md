# Папка товаров

Всё основное, связанное с каталогом товаров, собрано здесь:

- `products.js` — логика списков, добавления/удаления товаров, импорта и экспорта; карточки получают локальное изображение автоматически.
- `products.css` — оформление каталога и карточек товаров.
- `products.json` — исходный JSON-каталог с демонстрационными товарами.
- `images/` — локальные фото-превью товаров по категориям. Они хранятся в проекте, поэтому не требуют внешних фото-сервисов.

Страница `../tovari.html` подключает файлы из этой папки. Новые товары получают изображение автоматически по названию; если категория не распознана, используется `images/accessories.jpg`.
