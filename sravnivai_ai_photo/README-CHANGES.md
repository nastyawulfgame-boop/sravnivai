# Изменения в проекте «Сравнивай»

## Что изменено
- `index.html`: на стартовой странице оставлены только «Войти» и «Регистрация». Кнопка регистрации открывает форму в режиме регистрации.
- `login.html`: удалены ссылки «Главная» и «Каталог товаров».
- `tovari.html`: логотип «Сравнивай+» ведёт на `tovari.html`; добавлены рейтинг, форма оценки и отзывы с датами и общим количеством.
- `reviews.js`: рейтинг и отзывы сохраняются в браузере и переживают перезагрузку страницы.
- `auth/auth.js`: логика регистрации/входа вынесена в отдельную папку для удобства разработчика. Логин и хеш пароля сохраняются в браузере; успешный вход ведёт в каталог.
- `auth/README.md`: описание устройства авторизации и её ограничений.

## Запуск
Это статический сайт: Node.js не требуется.
1. Распакуйте архив.
2. Для локальной проверки откройте `index.html` в браузере. Для работы распознавания ИИ лучше опубликовать файлы на HTTPS-хостинге, например GitHub Pages.
3. Для публикации загрузите содержимое папки проекта в корень репозитория GitHub.
4. В GitHub откройте Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Ограничения демонстрационной версии
Авторизация и отзывы хранятся в `localStorage` одного браузера. Они не синхронизируются между разными пользователями и устройствами. Поэтому число отзывов на данный момент означает число отзывов в этом браузере, а не реальное общее количество людей на сайте. Для глобального рейтинга и реальной учётной записи всем посетителям нужна общая база данных и серверная/облачная авторизация. Не используйте клиентскую авторизацию как защиту коммерческого сервиса.

## Обновление: красные отзывы и загрузка фото
- Блок рейтинга и отзывов оформлен в красно-белой гамме.
- Выбор фотографии сделан через большую активную область с прозрачным полем выбора файла, чтобы надёжнее работать на мобильных устройствах.
- Поле принимает типы image/*; неподдерживаемые браузером форматы дают понятное сообщение с просьбой сохранить фото в JPG/PNG.
- Если похожих товаров в локальном каталоге нет, выводится явное сообщение «Товара нет в каталоге».


## Новые товары и готовые списки

В `scripttov.js` добавлены 6 демонстрационных списков с 5 товарами в каждом (30 новых товаров): «Электроника», «Одежда и обувь», «Дом и уют», «Красота и уход», «Спорт и отдых», «Аксессуары». Списки автоматически добавляются один раз при первом открытии обновлённой версии; существующие пользовательские списки и товары сохраняются, списки с теми же названиями не дублируются. Данные хранятся локально в браузере.

## Каталог товаров в отдельной папке
- Логика каталога и списков вынесена в `products/products.js`.
- Стили карточек и каталога находятся в `products/products.css`.
- Категории и демонстрационные данные собраны в `products/products.json`.
- Локальные фото-превью находятся в `products/images/`; карточки подбирают изображение автоматически по названию товара.
- `tovari.html` подключает CSS и JS из папки `products/`.
